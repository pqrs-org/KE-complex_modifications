Hardware requirement

These rules only fire while a 3-pedal USB foot switch is connected. The device is matched by device_if with vendor_id: 6790 (0x1a86, QinHeng Electronics / WCH) and product_id: 57382 (0xe026). This is the controller used by the common low-cost triple foot switch sold under many brands (PCsensor, KKmoon and similar OEM variants).

Check your own device in Karabiner-EventViewer → Devices. If your vendor / product id differs, edit the device_if conditions in the JSON before importing.

Factory key assignment

The pedals are expected to send plain a, b, c (left / middle / right), which is the factory default of these switches. If the pedals were re-programmed with the vendor's Windows configuration tool, change the from.key_code values accordingly.

Why the modifier layers

A foot switch has only three buttons, but a foot press can be combined with modifiers held on the keyboard. Each pedal therefore exposes six slots (no modifier, control, option, shift, command, hyper = control+option+shift+command), giving 18 actions in total. All 18 live in a single rule, so one toggle enables the whole set — one physical device, one entry.

Source and documentation

This rule is maintained in the open, together with four other rules by the same author: Finfra/karabiner-extensions — FootPedal. The repository holds the layer tables, the device notes and the reasoning behind the six-slot layout — useful if you want to remap a pedal rather than take the defaults.
