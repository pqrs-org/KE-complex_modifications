A complete Windows-style shortcut layer for macOS 15 or newer. It keeps physical Ctrl as Control and maps supported Ctrl application shortcuts explicitly, so Ctrl+Space, terminal control sequences, and remote-desktop modifiers can remain native.

The single rule includes Windows-style editing, Finder file actions, Terminal exceptions, Alt+Tab, context-aware Alt+F4, Home/End, screenshots, Windows-key system and window commands, and F1–F12 normalization. Win+Space invokes the standard macOS Control+Space input-source shortcut.

Scope: this community edition applies to every keyboard. If you want to convert only selected external Windows keyboards while leaving the MacBook keyboard unchanged, use the device-scoped installer in the full project.
