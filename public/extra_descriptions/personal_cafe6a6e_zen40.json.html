Zen 40 Layout: a minimal layout where alphanumerics, symbols, cursor movement and mouse control are all handled by about 40 keys around the home row, using layers. A numpad is on the left ⌘, symbols and arrows on Caps Lock, mouse keys on the left ⌥, and a Dvorak layer is toggled with the left ⌥+Esc. Source: cafe6a6e/karabiner-zen40

Key Behavior
Left ⌘ + right-hand keys Numpad: m,. → 1 2 3, jkl → 4 5 6, uio → 7 8 9, Space → 0. Use right ⌘ for shortcuts.
Right ⌘ ⌘ when held; tap alone for ⌃+Space (input source switch)
[ / ' Delete / Return
Caps Lock Tap for Esc. Hold for arrows on hjkl, and ` [ ] ( ) on yuiop, - on ;, = on n, ' on m, < > on ,., \ on /. Mouse motion scrolls while held.
Tab (hold) Shifted numbers (! @ # …) on the numpad positions
Left ⌥ (hold) Mouse keys: move on hjkl, click on uio / fds, scroll ← ↓ ↑ → on nm,.
Left ⌥ + Esc Toggle the Dvorak layer (physical Esc only). / is on the q key; ' and [ ] stay on the Caps Lock layer.
